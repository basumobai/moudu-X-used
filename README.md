# Mundo X Used

proxy-node Linux amd64 一键安装包。

## 一行安装

请使用 root 用户执行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/basumobai/moudu-X-used/main/install.sh)
```

脚本会依次安装必要工具、下载并校验 `proxy.zip`、安装 proxy-node、注册 `mnode`，完成后自动进入管理菜单。

以后随时输入：

```bash
mnode
```

也可直接执行：`mnode status`、`mnode start`、`mnode stop`、`mnode restart`、`mnode log`。
